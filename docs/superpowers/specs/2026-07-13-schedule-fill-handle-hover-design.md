# Стабильный hover для fill handle расписания

## Цель

Убрать мерцание курсора на маркере drag-to-fill, не меняя его положение, размер или механику заполнения.

## Причина

Маркер расположен с отрицательным смещением относительно правого нижнего угла ячейки. Его область захвата пересекает соседние ячейки. Их события `mouseenter` и `mouseleave` сбрасывают состояние маркера, из-за чего он появляется и исчезает при движении курсора по перекрывающейся области.

## Решение

Отрисовывать fill handle в отдельном слое поверх ячеек. Слой должен:

- сохранять нынешнее положение и размер маркера;
- принимать события указателя только в пределах самого маркера;
- иметь приоритет над соседними ячейками в перекрывающейся зоне;
- поддерживать видимость handle, пока указатель находится на нём;
- передавать существующему обработчику нажатие для запуска drag-to-fill.

## Проверка

Добавить регрессионную проверку структуры компонента: handle рендерится в overlay-слое, а ячейки не конкурируют с ним за pointer events. После изменения выполнить целевой тест, проверку типов и линтер.
